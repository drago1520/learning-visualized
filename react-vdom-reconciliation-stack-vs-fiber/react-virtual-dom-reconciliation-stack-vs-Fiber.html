In order for React to convert my jsx → UI, it must walk the entire components tree.

Every little face is a component. React visits each one and asks "did you change?".

How? – 2 ways.

Stack (legacy)

walk the entire tree at once and block additional re-renders in the meantime

Fiber shipped in React 16, so every current version already reconciles this way.

Example: Try to increase the counter while the Stack reconciler is running. U can't. But you can increase the counter with the Fiber reconciler.
